# Changelog

## 0.1.0

- Apps / Tree / List views with per-app grouping and subtree totals
- PSS-based memory and per-process swap on Linux
- RAM tab: breakdown of used memory (apps, zram, kernel, tmpfs, cache) and swap
- Clean up tab: unused `/tmp` and `/dev/shm` items, detached dev processes
- Kill a process or its whole tree
- macOS and Windows support via `sysinfo`
